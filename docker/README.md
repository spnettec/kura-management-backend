# 管理中心部署与首次设置

当前为 V52 同一隔离工作区候选，尚未应用原仓、提交推送或交付正式发行。应用内首次配置、真实 Cockpit 登录/提权、原生包安装和普通完整镜像已有各自保留证据；当前 Docker 界面增量的实际结果另见 reviews/registered-runtime-review-20261114.md，不重新执行已闭环初始化。

## 默认容器流程

Linux 主机在 Cockpit 的 `YOFC Console Setup` 页面选择 Docker，读取核定镜像目录。离线安装可选择对应 tar.gz 上传，确认文件已核实后导入。填写实例名称、HTTPS 和网关连接发布端口，点击“创建并启动中心”；工具自动创建独立持久卷。受理后可关闭页面，再通过原编号核对结果；不会重复创建或启动。默认配置不要求用户填写环境变量、任务密钥或 TLS 文件挂载，也不提供弱口令 PostgreSQL。准备独立 PostgreSQL 数据库，随后在中心设置页面输入连接信息。维护者仍可选择默认 compose.yml 的高级部署入口。

Linux 主机安装工具还提供容器选择、已发布端口的 HTTPS 就绪核对、可信安装指纹和安装凭据下载。凭据仅从选定的运行中 YOFC 容器以 `console` 身份读取，不生成或重置身份。需要已安装独立工具包、Cockpit 和本机 Docker Engine；工具使用固定本机 socket，镜像目录由安装包保护。macOS/Docker Desktop 的原生交付适配尚未实施，不能冒称所有平台已完成界面部署。

打开中心 HTTPS 设置页，先将浏览器安全详情中的证书 SHA-256 与主机安装工具显示的指纹核对，再上传下载的安装凭据。页面填写数据库、中心地址、gRPC 监听、组织与管理员，选择服务器证书/私钥和公开客户端 CA，核对后提交。首次阶段没有默认管理员，也不会在页面出现前初始化数据库。已有业务表的 schema 不接受首次初始化。成功后同一进程转入正式服务，以所选管理员登录；后续启动读取保存的配置。

CA 私钥留在外部签发方，不进入容器。临时安装身份只是服务器终端证书。中心 CSR 下载/外部签发后上传的完整流程、多管理员及签发 custody/多人审批仍按完整台账推进。

## 运行与维护

Linux主机工具的“Docker中心维护与升级”按原维护编号操作：先导入所需镜像，冻结所选中心，再确认停服。选择新镜像后点击升级，或在当前版本支持时完成维护并启动。后端沿用原数据卷，在原冻结仍有效时启动并核对下个运行代际，再恢复服务；历史容器和记录保留。界面刷新不重复派发，结果不明确时仅观察原编号，不自动降级、重试或删除数据。旧版本缺少维护启动能力时，需选择支持此能力的新镜像。此候选的实际验收范围和完整发行限制另见reviews/registered-runtime-review-20261114.md。

入口只准备状态目录并降权运行服务器，不先调用 `task-key-init` 或 `migrate`。只对新建空卷接管 root 所有权，不递归修改已有内容；异常所有者或非空 root 状态要求核对。已有安装凭据、密钥、生成版本、原请求和回执均保留。

Docker 健康检查只观察固定容器 loopback 的 `/health/live`。安装等待时 liveness 为200，`/health/ready` 为503；正式服务的 readiness 还检查数据库。这个 loopback 存活检查不认证对外证书信任或服务已经配置完成。

设置页可联合启用服务器 TLS 与客户端信任配置，无需人工重启；旧生成版本保留，pending 不视为批准。界面保存原 operationId 后仅发送一次，结果不明保持 UNKNOWN，后续只查询原编号。不能通过新编号、重启、重导出或删除记录绕过。完整 UNKNOWN 人工核定/恢复界面仍是内部待办。

保留 PostgreSQL 与完整状态卷，包括任务密钥、安装 generation、TLS/CA generation、指针及原业务记录。维护/升级前检查未决安装、TLS 与任务记录。并发写入与维护停止之间的完整协调仍须单独验证；当前检查不等于已交付完整升级事务。组织备份/恢复、独立 agent 本地身份/续期和正式 Linux 沙箱也继续内部待办。

## 旧部署兼容

`compose-legacy.yml` 保留显式旧部署入口及三项独立只读挂载：服务器证书、服务器私钥、公开客户端 CA；不挂载 CA 私钥或网关私钥。缺失宿主输入不会自动创建目录。此入口用于已有数据库、密钥和证书的部署，不自动生成任务密钥或签发材料；新部署使用默认向导。

构建维护者可使用 `docker build -f docker/Dockerfile -t yofc-management-console:latest .`。镜像构建和部署平台设置由维护者/安装工具负责，用户首次配置通过页面完成。完整多阶段、正式镜像升级及平台矩阵以各自实际证据为准，不能用本批运行阶段制品替代全部验收。
