## 行为

- 登录页、顶栏和详情抽屉提供“语言 / Language”切换，支持简体中文 `zh-CN`、英文 `en-US`。
- 优先采用有效的 `yofc.console.locale` 本地选择；首次访问按浏览器语言优先顺序匹配中英文。
  浏览器语言均不支持时回退中文。无效的已存选择被忽略；存储被禁用时仍可在本页切换。
- 即时更新导航、登录与校验、表格、角色、能力、任务状态、网络表单、接管同意、事务、倒计时和错误。
  同步 Ant Design locale、页面标题、HTML lang；日期采用所选语言及浏览器时区。
- 切换不会重建登录会话、SSE、表单或网络事务；已输入内容、已读结果及明确同意状态保留。
  对已经显示校验错误的字段重新校验，避免遗留上一语言的错误。
- 网关名称、用户输入、ID、协议码及原始任务 JSON 保留原值。原始网络诊断收在有本地化标题的详情中，
  便于排障；不把英文诊断假装成已翻译内容。认证、授权和协议错误码未改变。

## 代码

`src/i18n/messages.ts` 的每个键必须同时有中文和英文，调用点由 TypeScript 检查；
`core.ts` 负责选择、插值及协议码映射，`I18n.tsx` 提供 React 上下文、组件库 locale、日期与切换入口。
扩展语言时同步 locale 类型、词库、组件库配置与选择器，并补契约和浏览器覆盖。
错误状态保存原始类型和业务码，在渲染时翻译，因此已出现错误也能即时换语言。
